# Drift Run: Metro Edition

## Run locally

```sh
npm install
npm run dev
```

For a production build, run `npm run build`. The ready-to-host files are written to `dist/`.

## What changed

- The home screen has Maps and Metro Drive launch buttons side by side; multiplayer is no longer shown there.
- Metro Drive is a large freeroam city with a downtown grid, freeway loop, park, waterfront docks, and billboards.
- Settings now offers Performance, Balanced, and High graphics profiles plus an automatic Frame Saver.
- The home screen has a Controls button with the main keyboard controls, and the full control list remains in Settings.
